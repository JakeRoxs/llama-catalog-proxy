# sq-018: Reduce cognitive complexity of RunRecord.Validate()

## Objective
Extract cohesive private helper methods for workload, sample, and request validation so `Validate()` is a linear sequence. Preserve exact validation order, bounds, error strings/identities, short-circuit behavior, and nil/zero handling. Reduce cognitive complexity from 56 to below 15.

## Files
- `internal/benchmark/types.go` — only file in scope.

## Changes
- Extracted `validateWorkload(i, requests *int, reservedTokens *int) error` — workload metadata + sample iteration + per-sample validation + completion sample-count check.
- Extracted `validateSample(sample, iterations map[int]bool) error` — sample fields + duration check.
- Extracted `validateRequests(requests []RequestMeasurement, reservedTokens *int) error` — request measurements + reserved-token accumulation.
- `Validate()` is now a linear sequence of metadata checks + a single workload loop calling `validateWorkload` + final budget check.

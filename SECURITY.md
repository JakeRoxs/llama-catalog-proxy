# Security Policy

## Supported Versions

Security fixes are applied to the latest released version. Pre-1.0 releases may include breaking
configuration changes, which are documented in the changelog.

## Reporting A Vulnerability

Do not open a public issue for a suspected vulnerability or leaked credential. Use GitHub's private
vulnerability reporting form:

https://github.com/JakeRoxs/llama-catalog-proxy/security/advisories/new

Include affected versions, reproduction steps, impact, and any suggested mitigation. Avoid
including production API keys, internal URLs, model prompts, or request bodies in the report.
